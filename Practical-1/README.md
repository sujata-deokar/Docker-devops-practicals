# Practical 1: Docker Installation and Container Basics

## Objective
To understand Docker images and containers and practise basic Docker container management.

## Environment
- Platform: AWS EC2
- Operating System: Ubuntu 26.04.1 LTS
- Docker Version: 29.1.3

## Practical Tasks
1. Verify Docker installation.
2. Check Docker Engine status.
3. List available Docker images.
4. Run an Ubuntu container.
5. Execute Linux commands inside the container.
6. Inspect filesystem, memory and processes.
7. Exit and inspect container status.
8. Start and stop the container.
9. Remove the container.
10. Verify image availability after container removal.

## Result
Successfully created, inspected, started, stopped and removed an Ubuntu Docker container.
